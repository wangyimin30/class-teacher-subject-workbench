# 教师工作台

一款面向班主任与任课教师的本地化桌面工作台，用于整合班级管理、学生信息、家校沟通、课表安排、教学规划、作业背默、测评记录等日常工作。

本系统支持 Mac 与 Windows 桌面端使用，数据保存在本地数据库与指定文件夹中，不依赖浏览器缓存，适合教师长期记录、查询、导出和复盘日常工作。

## 主要功能

### 班主任工作台

- 整体看板：日程表、待办事项、近期事务、家校沟通提醒
- 课表管理：班级课程表、任教学科课程表、自选课名单、调课/换课/补课记录
- 学生管理：班级名单切换，学生详情、备注、班干部、联系方式维护
- 家校沟通：家访、请假、学习反馈、行为沟通、重要通知、家委工作等记录
- 请假管理：请假记录新增、筛选、修改、导出
- 小组合作：小组建设、合作项目、合作战绩统计
- 班级座位表：拖拽排座、随机安排、定期换座位、历史座位表保存
- 工作留痕：班主任德育、安全、班级管理等工作记录汇总
- 活动工具：随机点名、多人点名、计时器、抽奖等课堂与班级活动工具
- 系统设置：基础信息、本地数据文件夹、数据库、备份与恢复管理

### 学科教学工作台

- 教学规划：月视图安排每日教学任务，支持完成勾选
- 作业管理：作业任务、批改登记、近期作业统计
- 背默管理：背默任务、背默登记、近期背默统计
- 测评管理：学科测试、成绩录入、平均分、优秀率、及格率统计
- 任教班级管理：支持多个任教班级的数据接入、切换与同步
- 数据联动：教学规划中的作业、背默、测评可同步到对应管理页

## 本地数据存储

系统使用本地数据库保存核心数据，包括：

- 学生信息
- 课表数据
- 家校沟通记录
- 请假记录
- 作业与背默记录
- 测评成绩
- 小组合作记录
- 座位表版本
- 工作留痕
- 系统设置

页面刷新、关闭软件或重新打开后，数据不会丢失。

## 文件夹接入

系统支持在设置中接入本地文件夹，例如：

- 学生名单
- 学生简历
- 家访归档
- 课表文件
- 班级活动资料
- 请假条或凭证
- 数据备份文件夹

系统读取本地文件后，会将数据写入本地数据库。即使原文件被移动或删除，系统仍会保留最后一次成功读取的数据。

## 安装使用

请到 GitHub Releases 页面下载对应系统的安装包。

### Mac

下载 `.dmg` 文件，双击打开后，将应用拖入“应用程序”文件夹。

### Windows

下载 `.exe` 文件，双击运行安装。

## 开发运行

如果需要从源码运行项目：

```bash
npm install
npm run start
```

如果只运行前端预览：
```npm run dev
```

如果需要打包 Mac 版本：
```npm run build
npx electron-builder --mac dmg --arm64
```

如果需要打包 Windows 版本：
```npm run build
npx electron-builder --win --x64
```
